# Archived tools

* C/C++
  * [Milu](https://github.com/yuejia/Milu) - A higher-order mutation-testing tool for C.
    * [MILU: A Customizable, Runtime-Optimized Higher Order Mutation Testing Tool for the Full C Language](https://www.researchgate.net/publication/228609925_MILU_A_Customizable_Runtime-Optimized_Higher_Order_Mutation_Testing_Tool_for_the_Full_C_Language)
  * [CCMutator](https://github.com/markus-kusano/CCMutator) - A mutation generator for concurrency constructs in multithreaded C and C++ programs.
    * [CCmutator: A Mutation Generator for Concurrency Constructs in Multithreaded C/C++ Applications](http://www-bcf.usc.edu/~wang626/pubDOC/Kusano13CCmutator.pdf)
* Clojure
  * [mutcl](https://github.com/ds2643/mutcl) - A mutation-testing tool for Leiningen projects.
* Go
  * [manbearpig](https://github.com/darkhelmet/manbearpig)
  * [mutator](https://github.com/kisielk/mutator)
  * [Golang Mutation Testing](https://github.com/StefanSchroeder/Golang-Mutation-testing) - A collection of examples for experimenting with mutation testing in Go.
* Java/JVM
  * [muJava](https://github.com/jeffoffutt/muJava) - A mutation system for Java with method- and class-level operators.
  * [ConMAn](https://github.com/sqrlab/ConMAn) - A concurrency mutant generator for Java.
  * [Mutation Testing](https://github.com/bulentrahimkazanci/Mutation-Testing)
* JavaScript
  * [mutagen](https://github.com/lazywithclass/mutagen)
  * [perturb](https://github.com/bttmly/perturb)
  * [Cerebro](https://github.com/lazywithclass/cerebro)
* PHP
  * [Humbug](https://github.com/humbug/humbug)
* Python
  * [MutPy](https://github.com/mutpy/mutpy)
  * [mutpy (ds2643)](https://github.com/ds2643/mutpy)
  * [xmutant.py](https://github.com/vrthra/xmutant.py)
* Rust
  * [halfsleep](https://github.com/apoelstra/halfsleep)
  * [mutant](https://github.com/Geal/mutant)
